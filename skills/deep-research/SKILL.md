# 有来源的调研

1. 先明确要支持的决策、约束和成功标准；不为资料数量而扩大问题。
2. 优先查官方文档、源码、发布说明与标准；社区经验只作为补充，记录网址和核查日期。
3. 单点事实以直接原始证据为准；比较性、高影响结论尽量交叉验证，区分文档明写、实测与推断。
4. 同一项目的多页不算独立来源。矛盾须列出并说明采信理由，不将项目自述的性能数字当独立验证。
5. 用宿主可用的搜索、抓取或连接器；某个提供方缺失可使用等价能力。关键来源仍缺失时保留不确定性，不编造结论。
6. 给出推荐方案、代价、适用边界及不采用的理由。上游功能与当前安装版本分开核对，不据最新 README 擅自升级。

输出只需决策所需的结论、直接证据链接、矛盾/未验证项和下一步。调研建议不是高风险实施授权。
