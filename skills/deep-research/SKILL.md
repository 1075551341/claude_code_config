# 有来源的调研

1. **明确决策与深度分档（按需比例）**：先确认要支持的决策、约束与成功标准，不为资料数量扩大问题。
   - **L1（单点事实/API）**：直接核对官方文档、源码或发布说明。
   - **L2（方案对比）**：官方资料为主，辅以社区经验，说明代价与适用边界。
   - **L3（高影响架构/选型）**：至少 2 个独立可靠来源交叉验证，并标明核查日期与版本。
2. **来源优先级**：官方文档、源码、发布说明与标准 > 维护者文章 > 社区实践；记录网址和核查日期。
3. **三态证据与独立性**：严格区分 **`[已实测验证]` / `[文档明写]` / `[代码推断]` / `[未验证]`**；同一项目多页不算独立来源；矛盾须列出并说明采信理由，不把项目自述性能数字当独立实测。
4. **源缺失处理**：使用宿主可用检索或抓取能力；某个提供方缺失可换等价可靠来源，关键来源仍缺失时保留不确定性并标明 `[未验证]`，**不编造结论或假装已交叉验证**。
5. **输出建议**：给出推荐方案、代价、适用边界与不采用的理由；上游功能与本机当前版本分开核对，不据最新 README 擅自升级。

输出只保留决策所需结论、直接证据链接、矛盾/未验证项与下一步；调研建议不等于高风险实施授权。
