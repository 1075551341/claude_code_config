# TDD（显式启用）

1. RED：为一个预期行为写失败测试，运行并确认失败来自预期原因（而非语法或环境错误）。
2. GREEN：写使该行为通过的最小实现，不提前扩展未测试行为或添加无关分支。
3. REFACTOR：在测试保护下改进结构（共性逻辑收拢公共层），每步保持通过。

测试关注外部可观察行为及正向、边界、预期失败和回归场景；避免顺序依赖、真实网络与不可控时间，不得通过删改测试、放宽断言、复刻实现或过度 mock 掩盖集成缺陷。记录实际红、绿与重构输出并按验证标准标注证据；TDD 不替代任务风险所要求的独立审查。
