# 上下文与交接

在有意义的任务断点保存必要状态，不依赖固定模型窗口大小；宿主有可靠上下文指标时在接近预算前完成当前原子步骤并交接，否则按任务规模判断。

## 保留、边界与丢弃

- **保留**：目标与验收、已完成项及 `[已实测验证]` 命令/输出、关键决策及理由、**用户既有未提交改动 vs 本任务改动 & 既有基线测试状态**、**已排除方案与失败尝试（附一句理由，避免下轮重踩）**、未完成项与下一步、约束与未知项。
- **丢弃**：可重建的搜索过程、重复日志与寒暄；不把推测或未实测项写成已确认事实。

## 落盘与模板

- 优先使用项目已有文档（ADR、现有规格目录、变更记录）；确有跨会话需要且无既有结构时，落目标项目 `spec/<project>/`（可用方法库 `templates/artifacts/STATE.md`）；若本端方法库包含 `catalog/skills/handoff/SKILL.md`，单次交接亦可按需参照。小任务不建整套制品。
- 记忆能力可用时先查索引/已确认偏好再按需读取详情；写入前确认授权且不存秘密；不把记忆插件当唯一事实源或替代当前源码；系统原生压缩命令由宿主处理。
