# 工程检查参考

仅在对应任务需要时读取。

- 复用已有模块与依赖；局部问题最小改，共性/重复缺陷在公共层统一修正以便扩展迭代，不为假设未来加间接层。
- 严禁静默回退（silent fallback）、宽泛默认值或空捕获掩盖异常；缺前置条件、配置错误或异步失败直接暴露原因并向上传播。
- 保持可维护、可测试与可回滚；内部废代码可在影响面内清理，公共契约有意变更须提供迁移说明，并在变更后横向清扫同类点及清零旧引用。
- 尊重项目清单、锁文件、CI 与现有运行时；缺必要工具时说明缺口，不擅换包管理器或升主版本。
- 外部输入在系统边界验证；命令参数化，认证、授权与资源归属分别核验；难复现依赖（时间/随机/网络）在确需时采用可注入接口。
- 性能先测量再优化，关注热点、N+1、批量 I/O 与并发边界；修改后检查文件编码/BOM/行尾并同步文档、注释与配置示例。
- 新行为与缺陷修复补充正向、边界及预期失败测试，避免复刻实现逻辑或放宽断言换绿灯。
