# /discuss — 需求讨论与对齐

讨论需求、识别约束、对齐期望。非简单任务启动前必须先对齐。
访谈纪律（一次一问+推荐答案，≤5 问收敛；目标/约束/边界/优先级）SSOT → `skills/task-triage/SKILL.md`「Grill」节。

## 输出格式

```
## 需求摘要
[一句话核心目标]
## 验收标准
- [ ] 可量化标准 1
- [ ] 可量化标准 2
## 约束与边界
- 技术约束 | 时间/资源约束 | 不做的事: ...
```

## 门控

需求无歧义 ✓ | 验收标准可量化 ✓ | 用户确认 ✓（未过门控 → 回到 grill 继续澄清）
