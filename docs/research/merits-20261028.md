## 3. 已在 tip 的可保留优点（不要重做）

按「merit → 现行所有者 → 不要再加一层」排列。

1. **模型无关 + effort 外置** → `config/workflow.yaml` 头注释 + `scripts/workflow.py lint` + validate V21。不要把模型 ID / 档位 / thinking budget 写回 pack。
2. **完成 = 独立审查 PASS** → `completion.*` + CORE R1 + verification skill。不要「验证绿就算完成」旁路。
3. **两道 PASS 门** → `review.pass_requires` + `r20_replay.review_bars_ok`。不要第三道软门。
4. **≤3 轮，用尽 BLOCKED** → `review.max_rounds` / `on_rounds_exhausted` + Stop stdout。不要回到 5 轮或 DONE_WITH_CONCERNS 放行。
5. **简单不豁免审查** → task-triage + completion.required_on_tracks。不要只读/文档免审。
6. **五维分类（无模型匹配维）** → `skills/task-triage/SKILL.md`。不要恢复 ⑥。
7. **双角色：审查只找问题，改走 change-implementer** → `rules/AGENTS.md` + agents 契约。不要审改一体。
8. **每轮全新开审，禁止 resume** → hooks `is_resumed_subagent` + verification skill。
9. **图谱三时点 + 无图 deny（含 everything）** → `graph_freshness.py` + MCP.md。不要每次编辑 kg sync。
10. **everything 语义路由，非 Glob fallback** → MCP.md §4 + explore_router matcher。
11. **工具链地板，缺则 BLOCKED** → `config/toolchain.yaml` + V20。不要 5.1 / npm / pip 回退。
12. **Cursor 完成门不 followup** → Guard 1.2.17。不要把 followup 搬回 Cursor。
13. **R20 满足行三态（承认/反驳/弃权）** → workflow dimensions hint + gate_messages。gsd honest-verifier **已经吸收**，不是「后续候选」。
14. **llm-as-a-verifier 观察输出优先** → verification skill；不要把 1–20 分 / logprob 期望搬进 hook（那是累赘）。
15. **cull 后的高内聚面** → 9/26/6/14 + catalog 按需。不要把已并入 CORE / systematic-debugging / ship 的浅层组件装回来。
16. **薄壳挡上游同名技能** → 三个审查/分支完成薄壳。删了会让插件版接管。
17. **配置主干单调度面** → 改阶段/门控/完成定义只改 `workflow.yaml` 再 render。
18. **永久禁用 cbm / UA / sequential-thinking / aider-repo-map / ralph-loop / 竞品 code-graph plugin** → MCP.md 禁止项 + CORE R17。
19. **issue-tracker 相似匹配** → `_lib/issue_state.py`；hook 只注入，分类 SSOT 仍是会话契约。
20. **编码守卫 + prettier 保 EOL + bash 编码误用警告** → 已有 hook，不要再加一层「写文件兜底」。
